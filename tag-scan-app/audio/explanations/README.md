# audio/explanations/

Place explanation audio files here, one per game.

Each file must be named exactly `<GAME-ID>.mp3` (uppercase), e.g.:

```
10BAL.mp3
LANDR.mp3
MEMOR.mp3
PARKO.mp3
KAART.mp3
MASTE.mp3
RAADS.mp3
TRESR.mp3
DODVI.mp3
BRIEF.mp3
ZINDO.mp3
TEKEN.mp3
ACHTE.mp3
DOOLH.mp3
VRKLE.mp3
TIKBO.mp3
```

These files are played when the host taps **"Speel Uitleg Audio"** after scanning a tag.  
If a file is missing, the app shows an "audio niet gevonden" error.
